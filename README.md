# Tempo Clock — Flutter project

تطبيق ساعة بتصميم داكن حديث وواجهة عربية، يتضمن:
- ساعة رقمية تتحدث كل ثانية.
- ساعة عقارب مرسومة داخل Flutter من دون صور خارجية.
- عرض التاريخ المحلي حسب الجهاز.
- ساعة إيقاف مع تشغيل وإيقاف وإعادة ضبط.
- مؤقت تنازلي مع اختيار المدة.
- شريط تنقل سفلي باللغة العربية.

## بناء APK عبر GitHub Actions

1. أنشئ مستودع GitHub جديداً.
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع، بحيث يكون `pubspec.yaml` في الجذر.
3. افتح تبويب **Actions** وفعّل Actions إذا طلب منك GitHub ذلك.
4. شغّل سير العمل **Build Tempo Clock APK** من زر **Run workflow**، أو ادفع التغييرات إلى `main`.
5. بعد نجاح البناء، افتح عملية التشغيل الناجحة في Actions.
6. في أسفل صفحة التشغيل ستجد Artifact باسم `tempo-clock-release-apk`. نزّله واستخرج ملف APK منه.

## ملاحظات مهمة
- سير العمل يولّد ملفات Android الأصلية بواسطة `flutter create` داخل GitHub، حتى تكون ملفات Gradle متوافقة مع نسخة Flutter المثبتة وقت البناء.
- لا ترفع مجلد `.dart_tool` أو `build` من جهازك.
- هذا المشروع لا يحتاج صوراً أو خطوطاً أو مفاتيح API خارجية.
- ساعة الإيقاف والمؤقت يعملان أثناء بقاء التطبيق مفتوحاً؛ المؤقت لا يرسل إشعاراً إذا أُغلق التطبيق.
- إذا عدّلت `applicationId` أو إعدادات Android لاحقاً، راجع إعدادات المشروع وسير العمل.

## المتطلبات
Flutter stable حديث، وDart المرفق معه، واتصال بالإنترنت لتنزيل الحزم أثناء البناء.
